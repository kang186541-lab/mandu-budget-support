## 지출을 기록하려면

오늘 화면의 **+ 쓴 돈 기록하기**를 누르고 금액과 분류를 선택하세요. 기록 탭에서 날짜를 선택하면 그날의 기록을 확인하고 수정할 수 있습니다. 화면의 합계는 앱에 기록한 지출이며, 은행 잔액이나 모든 카드 사용액을 나타내지 않습니다.

## 영수증에서 금액을 잘못 읽었어요

글자가 선명하게 보이도록 밝은 곳에서 촬영하세요. 사진의 글자는 iPhone 안에서 인식합니다. 인식한 금액, 날짜, 가게 이름을 확인하고 필요한 내용을 고친 뒤 저장하세요. 모든 영수증에서 정확한 인식을 보장하지는 않습니다.

## 카드 문자가 자동으로 기록되지 않아요

앱의 **설정 → 카드 문자 자동 기록** 안내에 따라 Apple 단축어에서 개인용 자동화를 만들어야 합니다. 메시지 조건 뒤에 **새로운 단축어 생성 → 동작 검색 → 카드 문자 기록**을 선택하세요. 동작의 **문자 내용**에는 실제 **단축어 입력**을 연결해야 합니다. ‘승인’이나 ‘결제’를 직접 입력하면 받은 문자 대신 그 글자만 전달됩니다.

자동화로 전달된 기록은 가계부 앱을 열 때 가져옵니다. 첫 문자가 전달되기 전에는 ‘대기 중’으로 표시됩니다. 카카오톡이나 카드사 앱 알림은 이 문자 기능의 대상이 아닙니다. 자동화를 중단하려면 단축어 앱에서 해당 자동화를 끄세요.

## 다른 기기에서 기록이 보이지 않아요

앱 자체의 계정이나 서버 동기화 기능은 없습니다. iPhone의 iCloud 또는 컴퓨터 백업에 앱 데이터가 포함되는지는 Apple의 백업 설정에 따라 달라집니다. 앱 삭제나 기기 변경 전에 백업 상태를 확인하세요. 운영자가 기록을 원격으로 조회하거나 복구할 수는 없습니다.

## 알림과 권한

기록 알림은 앱 설정에서 켜고 시간을 선택합니다. 알림은 기기에 예약되며, iPhone의 알림 허용 상태에 영향을 받습니다. 카메라나 사진 권한은 영수증 기능을 사용할 때만 필요합니다. 해당 권한을 허용하지 않아도 직접 기록할 수 있습니다.
